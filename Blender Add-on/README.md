# Installation instructions

1) Paste the three files to: 

BlenderDir\Blender Foundation\Blender\3.4\scripts\addons

Blender Directory usually found in:
C:\Users\"Username"\AppData\Roaming\Blender Foundation\Blender\3.4\scripts\addons

2) In Blender, under Edit -> Settings -> Addons -> Community tab search 'Hausdorff distance' and tick the box to enable it
3) The addon panel is located in the UI so you cannot find it along with the 'Tools' and 'View' Panels you should extend the upper right corner of the UI and you'll see the Hausdorff panel
